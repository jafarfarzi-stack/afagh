# سامانه جامع آموزشی دانشگاه آفاق

پروژهٔ کامل یک سیستم دانشگاهی مدرن در دو نسل — هر دو از یک طراحی واحد (سند اصلی) پیاده‌سازی شده‌اند و E2E تست‌اند:

| | مسیر | پشته | توضیح |
|---|---|---|---|
| **کالبد مدرن** | [`afagh-next/`](afagh-next/README.md) | Next.js 14 + PostgreSQL + Drizzle + Redis + MinIO | سه داشبورد ایزوله، امضای الکترونیک، اتاق انتظار Redis، RLS کامل، Object Storage |
| **فاز صفر** | [`afagh-erp/`](afagh-erp/README.md) | Node خالص + SQLite (بدون وابستگی سنگین) | ۱۲ ماژول کامل آموزشی/مالی/اداری + تست بار ۲۰۰۰ کاربر |

## شروع سریع

```bash
./install.sh    # نقش‌ها + ۷۳ جدول + RLS + دادهٔ دمو + Redis + بیلد
./start.sh      # کالبد روی :8080  (دموی فاز صفر: ./start.sh --with-demo)
```

**استقرار پروداکشن با Docker (پیشنهادی):**

```bash
docker compose up -d --build     # یا: make up   → http://SERVER_IP:8080
make up-https                    # اختیاری: پشت Caddy با HTTPS خودکار (DOMAIN در .env)
sudo ./deploy-debian.sh          # سرور تازهٔ Debian 13: نصب داکر + رمزهای تصادفی + استقرار
```

**نصب توسعه با Docker (ویندوز / لینوکس / مک):**

```powershell
powershell -ExecutionPolicy Bypass -File .\install-docker.ps1 -WithDemoData   # ویندوز
./install-docker.sh --with-demo-data                                          # لینوکس/مک
```

جزئیات کامل: [`INSTALL.md`](INSTALL.md)

## انتقال داده از سرورهای قدیمی

پنل مدیر ← **🔄 انتقال داده از سیستم قدیمی** (`/admin/migration`) — چهار میز کار در یک صفحه:

| میز | کار |
|---|---|
| **دادهٔ پایه** | دانشجو، درس، ترم، ثبت‌نام، صورت‌حساب و تسویه — با «تحلیل اولیه» قبل از «ثبت نهایی» |
| **تطبیق کدها** | کد رشته/مقطع/ترم/درس/وضعیت سیستم قدیمی → موجودیت سامانهٔ جدید، با پیشنهاد خودکار |
| **شهریه و مالی** | انتقال فرمول‌های شهریه، ارزیابی امن آن‌ها و **مقایسه با شهریهٔ واقعی سیستم قدیمی** |
| **نمرات** | واردسازی در جدول موقت، مقایسه با نمرات فعلی سامانه، اعمال کنترل‌شده (نمرهٔ کیفی هم پشتیبانی می‌شود) |

ورودی همه‌جا **اکسل (`.xlsx`)** یا CSV است، برای هر بخش **قالب اکسل** دانلود می‌شود و همهٔ گزارش‌ها
خروجی اکسل دارند. راهنمای کامل: [`docs/MIGRATION.md`](docs/MIGRATION.md)

## حساب‌های دمو (رمز همه `123456`)

| نقش | کد ملی | مقصد |
|---|---|---|
| مدیر | 0000000001 | `/admin` — کارتابل + حقوق + بایگانی |
| استاد | 0011111111 | `/professor` — کلاس‌ها + امضای الکترونیک |
| دانشجو | 31412001 | `/student` — کارنامه + انتخاب واحد |

## قابلیت‌های شاخص

- **انتخاب واحد مقاوم در برابر هجوم**: ظرفیت اتمیک در Redis (Lua)، صف FIFO با نوبت زنده، ارتقای خودکار لیست انتظار، سپر نرخ
- **خط لولهٔ ۵ فیلتری**: مالی → ظرفیت → سقف واحد → پیش‌نیاز (درخت AND/OR) → تداخل کلاس/امتحان؛ خطای نرم = ارجاع به شورا با گردش کار
- **امنیت دفاع-عمقی**: RBAC + ممیزی زنجیره‌ای SHA-256 + **RLS سطح دیتابیس** (خواندن و نوشتن)
- **بایگانی الکترونیک**: فایل‌ها در MinIO (S3)، لینک امضاشدهٔ موقت، e-KYC
