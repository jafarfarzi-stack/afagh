# شواهد اجرای تست — ۲۰۲۶/۰۹/۰۸

خروجی‌های منتخب تست‌های واقعی این گفتگو؛ فایل‌های دارای before عمداً وضعیت قبل از اصلاح را ثبت می‌کنند. خروجی‌ها snapshot تاریخی‌اند، نه نتیجهٔ اجرای جدید در GitHub Actions.

گزارش اصلی: [تست سنگین](../../heavy-test-2026-09-08.md).

فایل credential، نشست مرورگر، dump دیتابیس، دادهٔ MinIO، باینری ابزار و لاگ نصب وابستگی‌ها در این پوشه قرار ندارند. مسیر موقت backup در گزارش به placeholder تبدیل شده است.

فاصله‌های انتهای خطوط و خطوط خالی انتهایی خروجی‌ها برای سازگاری با git diff --check پاک شده‌اند؛ نتیجهٔ آزمون‌ها تغییر نکرده است.
